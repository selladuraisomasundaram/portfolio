### How to display an image for any achievement:
In `index.html`, inside the corresponding `.achievement__img-box`, simply add or uncomment:
```html
<img src="assets/img/achievements/filename.jpg" alt="Title" class="achievement__img">
```
It will automatically display in the card with smooth hover effects, overlaying the placeholder.
